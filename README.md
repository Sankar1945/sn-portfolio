# Sankara Narayanan T. Portfolio — React Starter

## Run locally
1. Install Node.js LTS (if `node -v` is not recognized, install it and reopen your terminal).
2. Open this folder in VS Code or PowerShell.
3. Run `npm install`
4. Run `npm run dev`
5. Open the localhost URL shown in your terminal.

## Scope
Phase 1/2 React starter with seven sections and interactive 2D automation prototype. Phase 3 will replace the prototype with Three.js / React Three Fiber, a single connected 3D network, camera transitions and node popups.

Sanku uses the original artwork in `public/mascot/`. Reduced-motion mode uses the static idle portrait. The normalized APNGs match the 510 x 510 idle canvas and retain the original gesture timings.
